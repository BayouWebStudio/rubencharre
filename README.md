# Ruben Charre - Neo Traditional Tattoo Artist

Premium website for Ruben Charre, a verified neo traditional tattoo artist from San Luis Potosí, Mexico.

## Features

- **Bilingual Website**: Spanish primary with English toggle (localStorage)
- **Premium Design**: Black (#0a0a0a) theme with crimson red (#dc2626) accents
- **Mobile Responsive**: Optimized for all devices
- **Portfolio Gallery**: Interactive 8-image portfolio grid
- **Artist Information**: Verified Instagram profile with 42K+ followers
- **Modern UI/UX**: Smooth animations and transitions

## Artist Details

- **Name**: Ruben Charre
- **Instagram**: [@rubencharre](https://instagram.com/rubencharre) (42,026 followers) ✅ Verified
- **Location**: San Luis Potosí, Mexico
- **Specialization**: Neo-traditional tattoos ONLY
- **Style**: Vibrant color, Japanese-influenced, anime, demons, geishas
- **Studio**: Black Soul Tattoo (@blacksoul_tattooslp)
- **Sponsors**: @industryinksusa, @neekdna

## Technical Stack

- Pure HTML5, CSS3, JavaScript (ES6+)
- Google Fonts (Playfair Display, Inter)
- CSS Grid & Flexbox
- Intersection Observer API
- LocalStorage for language preference
- Optimized for performance and SEO

## Website Sections

1. **Hero** - Artist name, specialty, location, and stats
2. **About** - Artist biography, sponsors, and studio info
3. **Portfolio** - 8-image interactive gallery
4. **Services** - Neo traditional services offered
5. **Contact** - Instagram booking and location
6. **Footer** - Copyright and website credits
